# Сборка и выпуск

## Локальная сборка

Установите JDK 21, Android SDK Platform 35, Build Tools 36.0.0, NDK 27.2.12479018 и CMake 3.22.1.

```pwsh
.\gradlew.bat :app:assembleGithubDebug :app:testGithubDebugUnitTest
```

Для полной сборки дополнительно соберите Xray через `nova-xray/build.sh` и Mihomo через `tools/build_nova_proxy.sh` с Go 1.26 и `ANDROID_NDK_HOME`. Как вариант для Windows, утилита `tools/import_upstream_native.py` принимает официальный APK Nova v1.35.2 из [upstream Releases](https://github.com/confeden/Nova-Android/releases/tag/v1.35.2), проверяет SHA-256 и извлекает только опциональные нативные файлы. Рабочее дерево не отслеживает эти файлы. CI собирает их из исходников.

## GitHub Release

1. Перед первой загрузкой проверьте дерево, все отправляемые коммиты и архив APK на ключи, токены и конфигурации. Не загружайте историю, содержащую рабочие учётные данные. Зафиксируйте соответствие очищенной истории исходной версии.
2. Соберите `assembleGithubRelease` и подпишите APK отдельным ключом Enhanced. Для обновлений требуется одинаковая подпись. Держите хранилище и пароль вне репозитория. Проверьте APK через `apksigner verify --print-certs` и пересчитайте SHA-256.
3. Создайте тег Enhanced и Release. Имя APK должно совпадать с шаблоном `Nova_<version>.apk`. Приложение запрашивает последний релиз репозитория Enhanced и проверяет подпись перед установкой обновления.
4. Сохраните контрольную сумму, инструкции установки и известные ограничения. Для тестового релиза явно укажите статус пререлиза.
