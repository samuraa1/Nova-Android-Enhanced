# Nova Android Enhanced

**VPN-клиент для Android с адаптивным выбором транспорта.** Форк [Nova Android](https://github.com/confeden/Nova-Android) Брента. Приложение бесплатно и не добавляет рекламу, телеметрию или обязательную учётную запись для самого клиента.

## Подключение

1. Установите подписанный APK Enhanced на Android 7 или новее. Сборка поддерживает `arm64-v8a` и `armeabi-v7a`.
2. На главном экране выберите **AUTO** и нажмите кнопку подключения. В системном диалоге подтвердите разрешение Android.
3. В настройках можно выбрать стратегию или посмотреть короткий отчёт о сети. Пользовательские профили включаются через существующий список подключений.

**Auto** использует сведения Android и историю подтверждённых сессий. **Ограниченная сеть** раньше пробует NOVA и Opera. **Высокая скорость** отдаёт приоритет WARP и MASQUE. **Пользовательский** возвращает порядок и лимиты исходной цепочки. Явный выбор профиля применяется самостоятельно.

## Доступность

Работа зависит от внешнего маршрута, транспорта, оператора и условий провайдера. Без доступного внешнего пути VPN не восстановит интернет. При чистой установке некоторым сервисам нужна техническая регистрация устройства. Enhanced не включает общую учётную запись WARP и авторское API-реле upstream. Полевые результаты по белым спискам пока отсутствуют.

Прозрачный WSS-релей Telegram отключён в этом выпуске. Telegram использует выбранный VPN-транспорт.

Для блокировки трафика вне VPN используйте соответствующий переключатель Android вместе с Always-on VPN. Проверьте совместимость с выбранным раздельным туннелированием.
