# История изменений

## 1.36.0 · Enhanced

### Подключение

- Auto выбирает очередность по типу и валидации сети. Доступны режимы Restricted Network, High Speed и Custom.
- Подтверждённый транспорт хранится локально до суток. Отдельная ветка проверяет TCP-доступность для IPv6-only сетей. На стандартной сети политика SNI использует системную валидацию.
- При переходе к следующему транспорту завершение предыдущего поколения инициируется до ожидания его рабочего потока.

### Безопасность и диагностика

- Сборка использует отдельный Android application ID и отдельный URL обновлений.
- Из сборки исключены общий профиль WARP и учётные данные API-релея автора. Из шаблонов удалены частные ключи. При недоступной регистрации некоторые встроенные способы могут не подняться с чистой установки.
- Импортированные VLESS TLS параметры больше не отключают проверку сертификата.
- Прозрачный релей Telegram отключён в APK, поскольку включённая версия Go-ядра не проверяла сертификат в этом пути. Исходник Go исправлен. Обычный трафик Telegram маршрутизируется выбранным VPN-транспортом.
- Короткий локальный отчёт о сети, Private DNS и транспорте доступен на русском и английском.

### Инструменты

- Базовая и модернизированная сборки, CI для Android и проверка зависимостей PR, инструкции по профилированию и тестам.
- GitHub-история upstream и сведения о лицензиях сохранены локально. [Nova v1.35.2](https://github.com/confeden/Nova-Android/releases/tag/v1.35.2)
