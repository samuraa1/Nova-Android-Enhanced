# Дорожная карта

## Реализовано в 1.36.0

- Собрана исходная Nova v1.35.2. Зафиксированы результаты JVM-набора для сравнения.
- Добавлены четыре стратегии, ограниченный перебор, приоритет недавнего подключения и IPv6-ветка TCP-диагностики.
- Подключены локализованные настройки стратегии и короткий отчёт без адресов и ключей.
- Убраны общие учётные данные из сборки. VLESS TLS проверяет сертификат. Обновления обращаются к релизам Enhanced.
- Настроена отдельная сборка приложения, CI и восстановление опциональных нативных движков из проверенного upstream APK.

## Следующий этап

1. **Проверка сети.** Выполнить матрицу [BENCHMARKS.md](BENCHMARKS.md) на физическом Android и в лаборатории. По результатам пересмотреть бюджеты и предикаты выбора.
2. **Защита.** Покрыть Always-on, lockdown, kill switch и DNS leak тестами на устройстве. Подготовить версионированную миграцию секретов в Android Keystore с отдельными тестами чтения в двух процессах.
3. **DNS.** Измерить существующие DoH/DoT и Private DNS. Оценить DoQ только при актуальном запросе и результате сравнения с DoH на той же сети.
4. **Интерфейс.** Выделить единый поток состояния для главной, истории и диагностики. Добавить реальный график трафика на основе счётчиков TUN. Полноценный Compose UI требует сохранения всех точек входа, включая TV, плитку и виджеты.
5. **Производительность.** Собрать трассы Go/JNI/TUN, RAM, CPU и батарею на обеих сетях. При наличии узкого места оценить ограниченный Rust-прототип и принять решение по измерениям.
6. **Публикация.** Проверить очищенную историю, исходники и APK, затем проверить GitHub Actions на рабочей ветке и опубликовать подписанный релиз.

Для продолжения проверьте `git status`, историю ветки `main`, журналы Gradle и актуальный [CHANGELOG.md](CHANGELOG.md).
