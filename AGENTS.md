# Nova Android Enhanced

Рабочая ветка основана на Nova Android v1.35.2, коммите `b1959ea0e27d1dcaf20b7b3f1ad581b15a19e465`. Оригинальный репозиторий подключён как `upstream`.

Для публикации используйте ветку `main` из `samuraa1/Nova-Android-Enhanced`. В ней сохранена хронология основной ветки upstream с очищенными данными профилей. Идентификаторы затронутых коммитов отличаются от исходных. Сверяйте изменения upstream через отдельный remote и переносите проверенные изменения, чтобы секреты из исходной истории не вернулись при слиянии.

## Начало работы

1. Прочитайте [ARCHITECTURE.md](ARCHITECTURE.md) и [ROADMAP.md](ROADMAP.md).
2. Для сетевых изменений сверяйте гипотезы с [NETWORK_RESEARCH.md](NETWORK_RESEARCH.md).
3. Перед выпуском применяйте сценарии из [BENCHMARKS.md](BENCHMARKS.md) и [RELEASING.md](RELEASING.md).

## Контракты

- Интерфейс и VPN работают в разных процессах. Состояние, которое читают оба процесса, должно публиковаться атомарно. У каждого файла должен быть понятный владелец записи.
- Явный выбор протокола и источник импортированных профилей принадлежат пользователю. Автоматический перебор применяется к встроенному Auto.
- Привязывайте обход туннеля только к сокетам, которым действительно нужен исходный маршрут. Сохраните проверку TLS, лимиты сетевых попыток и отмену при остановке службы.
- В текстах для диагностики избегайте секретов, идентификаторов подключения, IP, SSID и URL импортированных профилей. Проверяйте отдельным сканированием рабочее дерево, публикуемую историю и состав APK.
- Проверяйте на обеих ABI. Поддерживаемая минимальная версия — Android 7. Исходная реализация встроенных транспортов находится в `nova-core/`, `nova-proxy/`, `nova-xray/` и `tools/`.
